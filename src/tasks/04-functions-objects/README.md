# 04. Functions and Objects

Цель блока: уверенно работать с функциями, объектами, группировкой данных и иммутабельным созданием новых структур.

## Темы

- функции как значения;
- объекты и динамические ключи;
- `Set` и `Map`;
- группировка данных;
- копирование выбранных полей;
- подготовка к задачам на обработку коллекций.

## С чего начать

Открой тренажер и решай задачи блока `Functions and Objects` по порядку.
