# 02. Modern JavaScript

Цель блока: разобраться с возможностями современного JavaScript, которые часто встречаются в рабочих задачах и на собеседованиях.

## Темы

- массивы и методы массивов;
- объекты;
- деструктуризация;
- spread/rest syntax;
- замыкания;
- `this`;
- промисы;
- `async/await`.

## Мини-задания

1. Отфильтровать массив чисел и оставить только положительные.
2. Преобразовать массив пользователей в массив имен.
3. Посчитать количество повторений слов в массиве.
4. Написать функцию с замыканием для счетчика.

## С чего начать

Открой `solution.ts` и реализуй функции через методы массивов, объекты и замыкание. Внизу файла есть примеры вызовов и ожидаемые результаты.

## Результат

После блока ты должен понимать, как обрабатывать данные и объяснять ключевые механики современного JavaScript.
