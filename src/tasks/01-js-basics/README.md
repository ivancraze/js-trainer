# 01. JavaScript Basics

Цель блока: уверенно освоить базовые конструкции JavaScript, которые часто проверяют на первых этапах собеседований.

## Темы

- переменные: `let`, `const`;
- примитивные типы данных;
- преобразование типов;
- условия: `if`, `else`, `switch`;
- циклы: `for`, `while`;
- функции;
- область видимости.

## Мини-задания

1. Написать функцию, которая определяет, является ли число четным.
2. Написать функцию, которая возвращает большее из двух чисел.
3. Написать цикл, который считает сумму чисел от `1` до `n`.
4. Написать функцию, которая проверяет, пустая ли строка.

## С чего начать

Открой `solution.ts` и замени `TODO` на свою реализацию. Внизу файла уже есть простые `console.log`-проверки с ожидаемым результатом.

## Результат

После блока ты должен уметь читать и писать простые функции без подсказок.
