# Учебный маршрут

Этот раздел содержит задачи для подготовки по JavaScript и TypeScript.

## Блоки

1. `01-js-basics` — база JavaScript: переменные, типы, условия, циклы, функции.
2. `02-modern-js` — современный JavaScript: массивы, объекты, замыкания, `this`, `async/await`.
3. `03-typescript-basics` — база TypeScript: типы, интерфейсы, generics, narrowing, utility types.

## Как проходить

1. Открой `README.md` внутри папки блока.
2. Прочитай цель блока и список тем.
3. Решай задачи по одной, не переходя к следующей теме слишком рано.
4. После решения добавляй короткие заметки в `notes.md`.
