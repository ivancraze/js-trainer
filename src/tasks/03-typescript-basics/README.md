# 03. TypeScript Basics

Цель блока: научиться описывать данные типами и понимать, как TypeScript помогает находить ошибки до запуска кода.

## Темы

- базовые типы;
- массивы и объекты;
- type aliases;
- interfaces;
- union types;
- narrowing;
- generics;
- utility types.

## Мини-задания

1. Описать тип пользователя.
2. Написать функцию, которая принимает массив пользователей и возвращает их имена.
3. Описать union type для статуса задачи.
4. Написать generic-функцию, которая возвращает первый элемент массива.

## Результат

После блока ты должен уметь писать простые типы и объяснять, зачем они нужны.
