# New Life

Учебный проект для пошагового изучения JavaScript с нуля.

## Цель

Проект нужен, чтобы последовательно проходить темы JavaScript, выполнять практические задачи и сохранять прогресс в одном месте.

## Структура проекта

Проект организован как набор папок с задачами. Каждая папка отвечает за отдельную тему или шаг обучения.

Текущая структура учебного маршрута:

```text
src/tasks/
  01-js-basics/
  02-modern-js/
  03-typescript-basics/
```

Внутри каждой папки могут находиться:

- условие задачи;
- решение;
- заметки по теме;
- дополнительные упражнения.

## Команды

Установить зависимости:

```bash
npm install
```

Запустить проект в режиме разработки:

```bash
npm run dev
```

Проверить сборку:

```bash
npm run build
```

Запустить линтер:

```bash
npm run lint
```
